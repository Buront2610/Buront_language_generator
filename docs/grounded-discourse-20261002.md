# 原文に根拠のある談話表現と長文処理の追加改善

## 基準と範囲

基準版は PR #3 のマージコミット `c7631aeab30d962ef0ccb55c1e97f289da47e632`。その tree は、前回評価した `f4147c78479d04741cbf6b6d8fce2b292e8d9be7` と同一の `eb563c45ad531f386f65e5ef1d73cdf5a1f6509d` です。

今回は自由生成ではなく、原文に既にある説明・逆接・謙遜の見せ方を増やす限定改善です。出来事、原因、他人の称賛、人物の優劣は補いません。S/Q は未学習のまま `null` であり、検証成功を自然さ・面白さの保証とは扱いません。

## 文法と生成の変更

- 説明の「〜からだ」は、`から` が SCONJ/mark、後続コピュラが同じ述語に結び付くことを確認し、重複した断定接尾辞を付けません。丁寧形・過去・否定の連鎖も検査します。出所を表す格助詞の「空からだ」や、別の節の通常の断定まで一律に禁止する修正ではありません
- 明示された主張に続く「〜からだ／からです」の説明に「何故なら」を置きます。理由本文はコピーし、主張の「と思う」や理由内の否定も保持します。既に理由導入がある文、引用・伝聞・疑問・条件・未対応の推量などは棄権します
- 濃いめでは、前文に続く独立した接続詞「しかし」を「だが」へ変換します。「が／けど」だけから対立を推測しません。「しかしながら」の一部分も置換しません
- 文書冒頭の正確な「大したことはしていない」と、直後の明示された完了行為「〜ただけだ」の組合せに限り、謙遜を「それほどでもない」へ実現します。達成の本文は保持し、他人の行為・未完了・予定・曖昧な文脈へ広げません。対象となる完了行為の述語も有限リストです。「私は大したことはしていない」は「私はそれほどでもない」へ変えると評価対象がずれるため、今回の構文では変換しません

新しい構文は前後の原文範囲、token ID、事実の特徴を束縛します。独立検証では元の IR から適用条件と出力を再計算します。生成時の派生キャッシュや宣言された逆翻訳を、検証の根拠として再利用しません。既存の怒り・悲しみ・時間切れの構文と、局所的な「時既に」の重複防止も残します。

## 参照作品との関係

[寺生まれのBさん](https://syosetu.org/novel/107412/4.html)、[決闘クラブ](https://syosetu.org/novel/107412/12.html)、[謎の改変物](https://kenkyonanight.xxxxxxxx.jp/oii.html) を確認しました。これらでは語尾だけでなく、立場、理由、逆接、達成と自己評価の連なりが使われます。

一方、人物の地位、他人の称賛、誤った因果、追加の出来事も作品の笑いを支えています。それを原文のない入力へ足す実装にはしていません。「何故なら」は原ログの根拠であり、改変物ページとの逐語一致として示したものでもありません。今回の少数の構文を、作品全体の語り口を再現できた証拠にはしません。

## 長文処理の変更

入力上限は 5,000 Unicode scalar、候補の出力上限は 12,000 scalar のままです。従来は合法な 5,002〜5,003 文字の出力を入力用上限で再解析し、保護値検査だけが失敗していました。入力文書生成と出力の保護値抽出を分離し、抽出ロジック・不正値拒否は共有したまま、それぞれの上限を適用します。

検索では MiniSearch 7.2.0 の OR 検索の生結果を元の語順で逐次集約します。反復語の寄与を省略したり乗算へ置き換えたりせず、スコアの加算順、順位、同点順序を保ちます。語ごとの一時結果キャッシュには上限を設け、クエリを切り詰めません。固定版の private 実行メソッドに依存するため、版・実行面・オプションの不一致では明示的に失敗させます。ライブラリ更新時は native の全結果一致テストが必要です。

BMP の文字列切り出しと出力範囲の計数も、Unicode scalar の意味を保って無駄な全文配列化を減らします。絵文字などの astral 文字には従来と同じ scalar 切り出しを使います。

## 評価の読み方

一般文の評価と性能測定は、入力、設定、資産、基準版を固定して比較します。新たに追加した陽性診断例は、事前の一般文セットと分けます。個々の計測成功は、任意の 5,000 文字、あらゆる端末、ブラウザー上の全操作を保証しません。

### 実測した改善と残件

- 既存の一般文16件のうち、理由2件と謙遜1件で新構文が表示されました。残る13件は候補の全文・順序とも旧版と同じです。標準／濃いめの違いは、この一般文16件では引き続き出ていません。逆接の濃さの違いは別枠の陽性診断例で確認しました
- 説明の「読みやすいからだからな」は解消しました。一方、時刻の格助詞を含む「午後三時からだからな」は残っています。文法上の分類は異なりますが、語感が重複気味な点まで解決したとは主張しません
- 5,000文字の合成解析では、旧版の標準ヒープでのメモリ不足に対し、改善版はエンジン16.311秒・NodeピークRSS 627.23 MiBで候補3件を返しました。旧版を明示4GiBで完走させた場合と、候補・検証・新規性評価を含む結果が一致しました
- 全文を実解析するAPI経路では、反復文字列5,000文字が17.415秒・候補2件、数量・引用を含む再構成した文章4,928文字が8.189秒・候補3件で完了しました。既定30秒のCoordinator、Python解析、独立検証を通しています。起動時間は別です
- APIのNode＋Python合計RSSは、25ms間隔の観測でそれぞれ約1,406.61／1,289.38 MiBです。メモリ負荷が小さいアプリになったという意味ではありません。実ブラウザーの操作、Windowsでの実行、任意の最大長入力の成功は未保証です
