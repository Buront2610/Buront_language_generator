## 実装の流れ

1. 原文の形態素・依存関係と各命題の条件から、理由→主張、謙遜→原文の行為、対象→証拠要求を認識します。「ので／から」だけでなく因果と判別できた一部の「ため」、同一文の「が／けど」で結ばれた不得意・未経験等の自己評価、具体的な対象に係る「根拠を教えてください」等も扱います。完了出来事は短い動詞一覧で決めず、原文の時制・完了形・主節の役割と主体を束縛します。入れ子の評価は本文を保持し、周辺の否定語だけで自己評価を認定しません。完成文全体への一致表ではありません。認識は系列・強度・出力文言を見ません
2. 認識済みの役割から、主張の理由づけ／控えめな自己提示／証拠要求という発話目的、立場、対象命題、前提命題を決めます
3. 原典の複数投稿で確認した操作を選び、原文スロット・文法部品を並べる節計画を作ります。節の前後、一文から二文への分割、二文から一文への融合、結論の名詞化、証拠質問の構文混交を別の実現として持ちます。資料・記録の名称は固定一覧にせず、明示的な根拠・判断・検証の係り受けと、提示／読む許可等の要求行為を分けて保持します
4. 節内では解析済みの丁寧形を埋込み可能な普通体にし、従来の独立検証済み語彙操作と合成します。五段・一段・サ変などの解析された活用を使い、否定・過去・進行形を保存します。予定や可能の限定を残す場合は「という事実」へ確定しません。同一の証拠要求内にある同意・伝聞・目的や、名詞化された対象はそのままコピーし、そこでの語彙置換も止めます。独立した先行文はその文自身の検証済み操作で扱い、要求の変換が無条件に占有しないようにしています。未対応の活用を推測しません
5. 検証器は生成器の認識証明や自己申告を信じず、原文から関係を認識し直し、役割ごとの一度だけの使用、境界、発話種別、数量、出典、局所編集、実現文、node、出力spanを再構築します

現行の `StructuralProgram` と認識関係はversion 3です。初回のversion 1、第2版の保持方法・謙遜／対象の種別に加え、命題の役割、入れ子の評価内容、完了出来事、証拠を載せた対象と要求する行為を区別しました。旧 `ConstructionProgram` はversion 2のままです。異なる契約の混在、未知version、改ざんしたロックは拒否します。再生成とreplayも同じ検証を通ります。出力の各断片から原文のコピー・活用・登録文法部品へ戻れます。

探索は最大8個の非重複な関係ブロック、最大12構造案です。2,000 scalarを超える長文では最大2構造案に絞ります。最初の文法のみの構成と、適用可能ならその語彙合成案を残し、ブロックごとの操作の巡回は維持します。長文で全ての実現候補を尽くすという約束はせず、原文解析と独立検証の時間を確保します。直積の無制限な探索をせず、実現の組合せを巡回させて既存語彙案と合成します。全経路合計36候補、表示3候補、各出力12,000 scalar、合計120,000 scalarの上限を維持します。上限後の原文も欠落させません。

## 実際の本文変化

原文：速度が重要なので、私はこの方法を選びました。

Bの内部生成候補例（最終20件診断では次の複合案は表示3案に残りませんでした）：
- 俺はこの方法を選んだ。何故かというと速さとスピードが重要だからだ。
- 速さとスピードが重要だから俺はこの方法を選んだということ。

前者は主張と理由の順序を逆にして二文へ分け、理由内の語彙を合成しています。後者は原文順を保って結論を名詞化しています。両方を同じ「順序変更」として数えません。

表示された別題材の例（強度3、設定とseedは定性診断記録を参照）：
- `価格が高すぎるので、私は購入をやめました。` → `俺は購入をやめた。何故かというと価格が高すぐるからだ。`
- `全然動かなかったので、私は装置を修理しました。` → `全然全く動かなかったから俺は装置を修理したということ。`
- `私は成果をアピールしました。報告の時間が短かったからです。` → `報告の時間が短かったから俺は成果をアッピルしたということ。`

節計画と語形・重複表現の合成が速度の一例だけではないことを確認できます。一方、助言の重複など生成できても表示されない組合せがあり、候補生成と選択の不足は分けて記録しています。


原文：大したことはしていない。机を片付けただけだ。

Bの候補例：机を片付けただけだ。それほどでもない。

完了行為を先に置いて謙遜を後へ回しています。一方、控えめな行為しか与えられていないので、原典の大げさな自己評価まで再現できた例とは扱いません。

これは対象命題を使う構文混交です。相手を作ったり、失敗の有無を断定したりしていません。質問の圧は変わるので強度3に限定します。
