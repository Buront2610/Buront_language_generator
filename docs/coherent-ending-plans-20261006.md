# 複数文の語尾計画を一貫させる · 2026-10-06

## 対象

基準は PR #4 のマージ後の main `4d918a56fba7e77c06788baa1cd33817086b5a12`、tree `d48f19862dbbe2c3c094e92c1434a6c29cf1dbbc`。PR #4 自体は変更せず、別の変更として扱います。LLM、新しい学習器、S/Qの疑似ラベルは追加していません。

## 最初に調べた非選択

前回の F02「急行を使った。移動の速度が必要だからです。」には、理由prefixと語彙編集を合成した検証済み候補がありましたが、すべて非選択でした。

選択処理は、検証・学習済み選好があればその優劣・読みやすさの制限を先に扱い、既選択との系統・操作・表現の多様性を比較します。S/Qがともにnullのこの例では、最初の構文系統内で構造新規性が「理由＋普通体」を選び、次に語彙系統、最後に語尾のみの系統が表示されていました。単純な合成ボーナスは、この多様性との交換になります。今回は selector・S/Q・新規性の定義を変更せず、合成案を無条件に表示させていません。

## 確認した具体的な欠点

旧版の rewrite planner は、普通体への中立的な活用変更と強調の「からな」を同じ上限（標準1回、濃いめ2回）で数え、候補内でも奇偶によって交互に選んでいました。独立検証にも同じ全語尾上限がありました。

原文:

```text
荷物を確認しました。予定を変更します。準備は十分です。今日は早く出発します。
```

旧版で表示される普通体案:

```text
荷物を確認した
予定を変更します
準備は十分です
今日は早く出発します
```

新版で表示される普通体案:

```text
荷物を確認した
予定を変更する
準備は十分だ
今日は早く出発する
```

原文の丁寧形を保つ案も残ります。強調案は普通体を基本に、標準では「からな」を最大1回、濃いめでは最大2回だけ使います。語尾の適用は既存規則と原文の形態・作用域・出典に通る箇所だけです。未登録の動詞活用、引用、伝聞、推量、疑問などを普通体へ強制する機能ではなく、あらゆる文の文体統一を保証しません。

## 実装

- 原文を変えずに許可済み編集の候補を一度列挙し、語尾保持／普通体／普通体＋上限付き強調の有限計画を組み立てます。既存の疎な語彙選択も残し、候補ループは6通り以内です
- 「からな」の追加だけが強調上限を消費します。独立検証も同じ上限を確認し、各普通体編集は原文から新しく作ったpermission guardで個別に照合します
- 生成した本文を別の規則の入力へ戻しません。候補間で編集オブジェクトを共有せず、検証へ計画側のキャッシュを渡しません
- ConstructionProgramやRewriteProgramの形式は変更しません。合法な部分編集を新しい操作として読み替える変更ではなく、既存の個別編集の組合せ方と表現上の上限を変えたものです。replayは引き続きengine hashと独立証明を必要とし、ロックしたnodeは保持します

### 数量直後の丁寧形での誤拒否

追加検査と独立レビューの双方で、「500円です→500円だ」「test@example.comです→…だ」が V-quantity に拒否される既存の問題を再現しました。文字列の役割抽出が、終止コピュラ「です」の先頭「で」を格助詞と見なしていました。

数量とそれ以外の保護値の役割抽出を共有し、終止境界（句読点・閉じ引用符・空白・末尾）の直前の「です／でした」に限って格助詞扱いをしません。「500円で買う」「500円で。」「500円ですしを買う」などの真の格助詞・曖昧な継続は従来どおり扱います。原値、単位、符号、比較条件、出現順、範囲、他の格助詞の検査は残します。

## 評価方法と限界

今回の指標は、原文IR・登録規則・出典から独立に列挙した普通体の適用可能箇所に対する、有限の活用変更の取り残しです。合法な別の語彙置換・構文置換が覆う箇所は対象から外します。幅0の理由prefixは本文の適用箇所を消しません。

- 語尾を変えた候補に、なお適用可能な語尾が原文のまま残るときだけ「部分変換」と数えます
- 語尾を一切変えない保持案は不適用として区別し、失敗には数えません
- 引用・未対応活用などはそもそも適用可能箇所ではありません
- 同じ原文IRに対する有限規則の再確認であり、独立した言語理解モデルでも、自然さ・笑い・人物らしさの人間評価でもありません

以前の35回帰・20制御・12初回評価済み・12旧保留は、すべて既知の回帰集合として再利用します。新しい保留入力は変更前に別途封印し、最終コードの凍結後にのみ実行します。いずれも合成された小規模な確認例で、無作為な自然文や人間品質ラベルではありません。

### 保留で確認した未解決の範囲
